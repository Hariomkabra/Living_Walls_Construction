A sleek and modern real estate website where users can explore, filter, and select their dream homes.

## ✨ About the Project
Living Walls Construction is a responsive and visually appealing real estate platform built to provide a seamless home-search experience. It allows users to:

Browse through beautifully listed properties

Filter homes based on preferences

View detailed information about each property

Navigate easily on both desktop and mobile devices

Whether you’re house-hunting or just window shopping, this platform brings your dream home closer with an elegant interface.

## 💻 Tech Stack
HTML5 – Structure of the site

CSS3 – Styling and responsiveness

JavaScript – Interactivity and functionality

Netlify – Hosting and deployment

## 🚀 Features
🏠 Interactive homepage with featured listings

🔍 Filter and search options for easy property discovery

📱 Mobile-friendly design

📸 Image gallery for property previews

⚡ Fast and smooth user experience


## 📦 Deployment
This website is deployed using Netlify. Any changes pushed to the main branch are automatically updated on the live site.
